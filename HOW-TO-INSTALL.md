# How to install plugin manually

1. [Install Decky Loader plugin](https://github.com/SteamDeckHomebrew/decky-loader#installation)
2. Go to Desktop mode of your Steam Deck and download latest release of the plugin from [Releases](https://github.com/eavesr/HomeMaster/releases)
3. After installation, open Quick Access Menu by pressing `...` button on your Deck and go to the Decky menu
4. Go to ⚙️ **_Settings_**, then **_General_**. Scroll down to **_OTHER_** and enable **_Developer mode_**
5. After that you'll see 2 new options appear on the left side of screen, go to the **_Developer_** tab.
6. Finally, press the **_Browse_** button and select the zip file with plugin that you downloaded earlier

At this point you can disable **_Developer mode_** if you want to.
